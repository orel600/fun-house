# דף דמות מג'מיני -> דמות תלת-ממד על השלד של KayKit

הכלים של הפיילוט (30.10.2026). לא חלק מהמשחק. התוצאה: `art/pilot/PilotHero.glb`, ש-`tools/build3d.js` אורז למשחק.
התוצאות, העלות והמסקנות: הפרק "מבצע ג'מיני" ב-[docs/3d-assets.md](../../docs/3d-assets.md).

הכל חינם. Python 3 עם: `pip install gradio_client trimesh fast_simplification pygltflib scipy pillow numpy`.
מריצים מתיקייה ריקה (נוצרות בה `crops/` ו-`gen/`):

0. רק אם ליד הדמות מרחף משהו שלא שייך לגוף (כמו הניצוץ של ניר): `python clean.py <דף.jpg> sheet.png x0,y0,x1,y1 ...` מלבין אותו, וממשיכים עם `sheet.png`.
1. `python crop.py <דף הדמות.jpg> crops`: חותך מלפנים, מהצד ומאחור. רקע לבן. את העמודות והגובה של כל זווית, ואת קו הקרקע אם יש, מוצא `sheet.py` לבד.
2. `python hunyuan.py`: הצורה מ-Hunyuan3D-2mv. הצבע של השרת החינמי לא עובד (נכשל, או דורש מנוי PRO), לכן:
3. `python decimate.py`: עד 5,600 משולשים.
4. `python paint.py <דף הדמות.jpg>`: הצבע. כל משולש לוקח את הצבע שלו מהזווית בדף שרואה אותו הכי טוב, והטקסטורה היא הדף עצמו (512). משולשים שאף זווית לא רואה (בתוך הגלימה, מתחת לבית השחי) מקבלים צבע של שכנים.
5. `python rig.py PilotHero.glb`: השלד של האביר בלי שום שינוי, והמשקלים (איזו עצם מזיזה כל נקודה) מועתקים מהאביר לפי הנקודה הקרובה. לכן כל האנימציות של KayKit עובדות. שם הקובץ הוא גם שם הדמות (`PilotHero_Body`).
   - `--apose`: כשהידיים בדף יורדות באלכסון ולא בתנוחת T. מוצא את הזווית מהדמות, ומסובב את עצמות הזרוע של האביר לאותה זווית לפני העתקת המשקלים. האנימציות של KayKit קובעות את הסיבוב המלא של כל עצם, אז הן מתנגנות כרגיל. הגודל נקבע לפי הגובה.
   - `--pack`: תרמיל גדול על הגב. מכווץ אותו קצת, וכולו זז עם החזה, בלי משקלים מהזרועות.
6. `python animtest.py 2`: בדיקה בלי המשחק, עם האנימציות של KayKit 2.0 שהמשחק מנגן: עמידה, ריצה, חרב, כישוף, מוות ועידוד. התמונה ב-`gen/anims.png`. בלי `2`: האנימציות הישנות של האביר.

הדמות של ניר (`art/heroes`): `clean.py nir-sheet.jpg sheet.png 600,315,770,495 1290,315,1428,495`, ואחר כך כל הצעדים, עם `rig.py NirHero.glb --apose --pack`.
