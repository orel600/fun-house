description: סיום עבודה. מעדכן מ-main, בודק, מבקש מהמשתמש לנסות, כותב ביומן ופותח בקשת מיזוג (PR) עם הסבר בעברית
---

סיים את העבודה הנוכחית לפי הסדר. לפני כל שלב, משפט אחד פשוט למשתמש: מה אתה עושה ולמה. אם שלב נכשל, עצור, הסבר במילים פשוטות, ושאל לפני שממשיכים.

1. **ענף.** אם אתה על main, צור ענף: `git switch -c feature/<תיאור-קצר>`. השינויים שלא נשמרו עוברים איתך.
2. **מה השתנה.** בדוק ב-`git status` וב-`git diff origin/main` מה השתנה. אם נמחק קובץ שהמשתמש לא ביקש במפורש למחוק, עצור ושאל.
3. **עדכון מ-main.** `git fetch origin`, ואז `git merge origin/main`. אם יש התנגשות, הסבר למשתמש מה התנגש, ופתור כך ששני השינויים נשמרים. אם לא ברור מה נכון, שאל.
4. **בדיקה.** אם Playwright מותקן, הרץ `npm run check` ותקן עד שהכול עובר. אם הוא לא מותקן, אמור שהבדיקה תרוץ ב-GitHub. מכניקה חדשה צריכה שלב משלה בבוט ובדוח של `tools/check.js` (ראה CLAUDE.md).
5. **ניסיון של המשתמש.** בקש מהמשתמש לפתוח את `index.html` ולנסות את מה שהשתנה. כתוב לו בדיוק מה לעשות ומה אמור לקרות. ממשיכים רק אחרי שהוא אישר שזה עובד ומרגיש נכון.
6. **יומן.** רשומה בראש היומן ב-`claude-channel.md`: מה נעשה, מה הוחלט, ומה ה-Claude השני צריך לדעת. החלטה שמשנה את התכנון נכנסת גם ל-`game-design.md`, והחלטה טכנית גם ל-`CLAUDE.md`.
7. **שמירה והעלאה.** commit עם הודעה קצרה, ואז `git push -u origin <שם-הענף>`.
8. **בקשת מיזוג.** `gh pr create` עם כותרת בעברית, וגוף קצר לפי `.github/pull_request_template.md`:
   - `## מה נעשה`: נקודה או שתיים. מה השחקן ירגיש, בלי קוד.
   - `## למה`: מי ביקש ומתי, ואיזו בעיה או רעיון זה פותר.
   - `## איך בודקים`: רשימת `- [ ]` של מה בדיוק לנסות, ומה עלול להישבר.
   - `## ל-Claude השני`: רק אם יש משהו שהוא חייב לדעת.

   בלי שלושת הפרקים הראשונים, הבדיקה "תיאור ה-PR" ב-GitHub נכשלת. אם gh לא מותקן, תן למשתמש את הקישור ש-`git push` הדפיס: GitHub ממלא את התבנית לבד, ותכתוב לו מה להדביק בכל פרק.
9. **הבדיקה ב-GitHub.** `gh pr checks --watch`. ירוקה: ספר למשתמש. אדומה: קרא את הדוח, הסבר במילים פשוטות מה נכשל, תקן ודחוף שוב.
10. **לא ממזגים כאן.** תן למשתמש את הקישור ל-PR. מיזוג רק כשהבדיקה ירוקה והמשתמש אמר במפורש למזג, ותמיד עם סיכום קצר שנכנס להיסטוריה של main:
    `gh pr merge <n> --merge --delete-branch --subject "<כותרת בעברית> (#<n>)" --body "מה נעשה: ... | למה: ... | אישר: <מי>"`
    ואחריו `git switch main` ו-`git pull`. מיזוג בלי `--body` נחסם אוטומטית.
