# מפת הקוד: מה יש בכל קובץ

הועבר מ-CLAUDE.md (1.11.2026) כדי שתחילת כל סשן תהיה קלה. **קובץ חדש = שורה כאן.** קוראים את השורות הרלוונטיות (grep) לפני שנוגעים בקוד.

| קובץ | מה יש בו |
| --- | --- |
| `css/style.css` | עיצוב הממשק. הכלל `[hidden]` בראש הקובץ חובה, בלעדיו כל המסכים מוצגים יחד |
| `js/version.js` | מספר הגרסה בפינת מסך הפתיחה: `v0.3.18.57` = ראשי.שלב.עדכון.בנייה. השלבים וההסבר ב-roadmap.md, בפרק "גרסאות". כשנגמר שלב, Claude מעלה את `STAGE` ומעדכן את `STAGE_FROM`. כשניר מדווח על באג, שואלים אותו מה המספר |
| `js/core.js` | קנבס, צבעים (`C`), פונקציות עזר, שיא |
| `js/lang.js` | **כל הטקסט שהשחקן רואה**, בעברית ובאנגלית, בטבלה `TEXT`. `T('מפתח')` מחזיר את הטקסט בשפה הנוכחית, ו-`DIR` את כיוון הכתיבה |
| `js/audio.js` | צלילים: `sfx('מזהה')` מכל מקום, והשתקה. הצלילים והמספרים שלהם ב-`SOUNDS`, והקבצים ב-`sounds/` (מתנגנים דרך Web Audio מתוך `js/sounds-data.js`, שנבנה ע"י `tools/build-sounds.js`. לא `<audio>`: באייפון הוא תקע את המשחק בכל צליל) |
| `js/data.js` | סוגי אויבים, הבוסים, השלל של כל אחד (`drop`) ושדרוגים (השמות שלהם ב-lang.js). לכל אויב חומרים (`tags`), ומהם נקבעות החולשות שלו |
| `js/dmg.js` | שישה סוגי נזק: צבע, צורה, ומה כל אחד עושה בפגיעה, וטבלת היעילות של סוג נזק מול חומר. המספרים באובייקט `DMG` |
| `js/resources.js` | **כל המשאבים** בטבלה אחת (`RES`): אייקון, משפחה, נדירות ומחירי שוק, ומה מוצג בפס העליון בכל מקום. משאב חדש נכנס רק לכאן ול-lang.js, והבדיקה נכשלת אם אין לו שני מקורות ושימוש |
| `js/nodes.js` | עצים, סלעים, שיחים, עורקי מתכת ותיבות בזירה: ההתקפה האוטומטית פוגעת בהם ומפילה משאבים, ויצורי משאבים שומרים עליהם. מה מופיע ומתי באובייקט `NODES` |
| `js/loot.js` | שלל: דרגות (רגיל עד אגדי) עם עמוד אור, אויבי עלית, פיצוץ שלל, הריגה ראשונה היום, מזל עם הגנה וסיכום בסוף ריצה. ציוד בעולם (`lootRoll`): מוטה לנשקים של הדמות (`arms` ב-HEROES) עם מזל שמבטיח אחד, ושכבה שעולה עם רמת הדמות. המספרים ב-`LOOT` |
| `js/weapons.js` | סוגי הנשק (`WEAPONS`): חרב, גרזן ופטיש מניפים מקרוב, קשת יורה חצים, מטה ושרביט יורים קסם שמתביית. כל פריט נשק ב-gear.js מצביע על סוג (`w`), והתקיפה האוטומטית באה ממנו. בקוד הצדדים נשארו `sword` (מקרוב) ו-`gun` (מרחוק) |
| `js/save.js` | שמירת התקדמות בין ריצות: רמת דמות, תרמיל, ציוד, כפר, קווסטים (`SAVE`). כל מערכת קבועה קוראת וכותבת רק דרכו. היום נשמר בטלפון, ובענן מחליפים רק את `SAVE_STORE` |
| `js/state.js` | `reset()`: מצב התחלתי לכל ריצה |
| `js/run.js` | הריצה בזירה: אורך, תחנות (גל ענק, אויב-על), ניצחון כשהבוס בסוף מובס, וכמה האויבים והשחקן מתחזקים. המספרים באובייקט `RUN` |
| `js/spawn.js` | הופעת אויבים: בודדים וגושים. המספרים באובייקט `HORDE`, ומתי כל מפלצת (Quaternius) מצטרפת: `HORDE.monsters` |
| `js/arenas.js` | סוגי זירות (`ARENAS`, אוראל): כל ריצה יודעת באיזו זירה היא (`S.arena`), ולכל זירה אויבים, חומרים, צבע רצפה וניצחון משלה. `classic` היא הזירה הרגילה, `waves` זירת גלים: 10 גלים עם הפסקות, מונה "גל 3/10" ובוס בגל האחרון. נכנסים מכפתור בכרטיס של שער בעולם |
| `js/arena-load.js` | עומס בזירה (`ALOAD`): אויב שנשאר רחוק קופץ קרוב, מעל `HORDE.cap` הרגילים הרחוקים נעלמים, וכדורי XP רחוקים מתאחדים לאחד. נקרא מ-update.js |
| `js/combat.js` | פגיעה, נזק, החלפת נשק |
| `js/skills.js` | סקילים וקומבו (אוראל): עד 3 כפתורי סקיל בזירה, הראשון מהנשק והשאר משדרוגים. קומבו בין סוגי נזק (חשמול, קפוא, נמס, הלם) נקרא מ-`onHit` ב-dmg.js, אז כל מקור נזק מקבל קומבו לבד. המספרים ב-`SKILLS` בראש הקובץ |
| `js/flute.js` | ערכות מראה למתקפות של דמות אישית (`THEMES`, `heroTheme()`): החליל של אוראל. render.js, skills.js ו-render3d.js מציירים דרכן |
| `js/spark.js` | הניצוץ: ערכת המראה של ניר (`THEMES.spark`). יריות כלהבונים, גצים במכת חרב, טבעת להבונים וברק גצים. המספרים ב-`SPARK` |
| `js/divine.js` | ברק אלוהי (`DIVINE`): אחרי שני אויבי-על בריצה, 5 שניות שבהן כל החפצים המסתובבים בכוח מלא |
| `js/rescue.js` | פיוחו מצילה (`RESCUE`), לכל חיית מחמד: מתחת ל-30% חיים, בסיכוי, פריט שמעלים אויבים קרובים. הפריט לפי החיה (`PET.kinds[...].rescue`) |
| `js/parosh.js` | הפרעוש, החיה של אוראל (`PET.kinds.parosh`, `PAROSH`): מתגנב לאויב, חוטף שלל ומביא. מודל `parosh1` מדף ג'מיני |
| `js/arenaui.js` | זירה נקייה (`ARENAUI`): פס חיים רק למי שנפגע ולאויב-על, מספרי נזק מתמזגים (`dmgFloat`), חץ לאויב-על, והפס העליון שקט בקרב |
| `js/streak.js` | רצף הריגות (`STREAK`): מילה גדולה למעלה ב-10, 25, 50 ו-100 הריגות ברצף |
| `js/ult.js` | אולטימייט, "פרץ הפנס" (`ULT`): מתמלא מהריגות, ופוגע בכל אויב על המסך. כפתור משמאל לקשת. מקלדת 4 |
| `js/spell.js` | כישוף מיוחד (`SPELL`): קפיצה, ריפוי או מכה. בוחרים בתחילת ריצה, והבחירה נזכרת. מקלדת 5 |

| `js/orbit.js` | החפצים המסתובבים (אוראל): מה שלבוש במשבצות orbit מסתובב סביב הדמות בזירה. אש שורפת, כפור מאט, אבן עוצרת יריות ובולעת מכה, עלה מרפא, תלתן נותן מכה קריטית ושלל. המספרים ב-`ORBIT` |
| `js/fuse.js` | התכת חפצים מסתובבים בנפחייה (חפצים משולבים, שלב 2): שני חפצים ומשאב נדיר (🌟), סיכוי גלוי, ויוצא חפץ עם החלקים של שניהם (עד 3). כישלון: המשאבים הולכים, ובשלושה חלקים גם החפץ השני (💎 מגינה). המספרים ב-`FUSE`, הלשונית בחלון הנפחייה (aging.js) |
| `js/boss.js` | הבוס שלומד את השחקן (סוגי נזק, מקרוב או מרחוק, תנועה), כולל זעם כשבורחים ממנו |

| `js/bonus.js` | הרעיונות של אוראל: דלת זהב וחדר בונוס, פריטים באזורי סכנה. כל המספרים באובייקט `BONUS` בראש הקובץ |
