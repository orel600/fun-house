# מידול חינמי מתמונה: ניסוי ראשון (4.11.2026)

נשק לדוגמה: `icons/ui/gear/dragonBlade.png`. השוואה: [dragonBlade-compare.png](dragonBlade-compare.png).

## מה יצא
- **TRELLIS** (`trellis-community/TRELLIS`): עבד, כ-25 שניות למודל. 13.4K משולשים, 790KB. אחרי הקטנה (simplify + טקסטורה 512 WebP): 4K משולשים, 89KB.
- **Hunyuan3D-2.1** (`tencent/Hunyuan3D-2.1`): צורה בלבד עבדה, 258K משולשים, 4.6MB, בלי טקסטורה. צורה+טקסטורה נחסמה במכסה.
- **Hunyuan3D-2mini-Turbo**: השרת החזיר שגיאה.

## הבעיה: שני המודלים בנו לוח שטוח
העובי יצא 0.6%-2.5% מהגודל, ריבוע עם התמונה מודפסת עליו, ולא חרב. רקע לבן במקום שקוף לא עזר.
הסיבה כנראה התמונה: אייקון באלכסון, עם זוהר וניצוצות סביב. המודלים קוראים אותו כמדבקה.

## מה לנסות בפעם הבאה
תמונת מקור שנוצרה בשביל מידול: החפץ לבד, זקוף, במבט שלושת-רבעי עם עומק נראה, בלי ניצוצות וזוהר, רקע אחיד. אפשר לייצר כזו מהאייקון ב-Creative Claw.

## מכסה
המכסה החינמית של ZeroGPU ב-Hugging Face נגמרה אחרי 3 ריצות (2 TRELLIS ועוד Hunyuan אחד): בערך 5 דקות GPU ביום. Hunyuan מלא מבקש 270 שניות לריצה, כלומר לכל היותר ריצה אחת ביום. TRELLIS זול בהרבה.

## הערה למי שמחבר למשחק
GLTFLoader לא טוען GLB מ-`file://` (fetch חסום), לכן מודל צריך להיכנס דרך `build3d.js` כמו ה-KayKit.
הטוקן בסביבה נקרא `HF` ולא `HF_TOKEN`.
