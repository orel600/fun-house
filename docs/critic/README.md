# המבקר: דוח ביקורת על המשחק

ניר (1.11.2026): "מבקר שתפקידו לעבור על המשחק ולתת ביקורת בהגשת דוח. אני עובר על הדוח ומסמן עם מה אני מסכים ומה צריך לתקן."

## איך זה עובד

1. **הכלי** (`tools/critic/run.js`) משחק במשחק כמו שחקן חדש וכמו שחקן מתקדם, בתלת-ממד, בשני גדלי טלפון (1280×590 של ניר, 844×390 אייפון) ובשתי שפות. הוא מצלם כל עצירה ומודד.
2. **Claude** עובר על הצילומים והמספרים, קורא קוד כשצריך, וכותב עד 20 ממצאים ל-`docs/critic/<תאריך>/findings.json`.
3. **ניר** מסמן בדף הסימון מסכים / לא מסכים. המתאם הופך את מה שאושר למשימות ב-roadmap.md.

## הרצה

```
node tools/critic/run.js              # כ-15 דקות בתלת-ממד, בלי כרטיס גרפי
node tools/critic/run.js --gfx 2d     # כ-3 דקות
node tools/critic/run.js --only n-en  # רק הטלפון של ניר באנגלית
```

הפלט ב-`tools/critic/out/<תאריך>/` (לא נכנס לריפו): `metrics.json`, צילום PNG לכל עצירה, ו-`small/` עם JPG ברוחב 600. את הצילומים שהממצאים מפנים אליהם מעתיקים ל-`docs/critic/<תאריך>/`.

השחקן המלא (חדש, מתקדם, השומר והזירה) רץ ב-`n-en`. בשאר השילובים רק סיור החלונות של שחקן מתקדם, כדי לבדוק פריסה ושפה.

### מה נמדד

| מדד | מה זה |
| --- | --- |
| `uiPct` | כמה אחוז מהמסך מכוסה בממשק (רשת של 50×30 נקודות) |
| `small` | כפתורים קטנים מ-44 פיקסלים |
| `overlap`, `textOverlap` | כפתורים או טקסטים שעולים זה על זה |
| `clipped` | טקסט חתוך או יוצא מהמסך |
| `scrollWins` | חלונות שהתוכן שלהם גולל |
| `frameMs` | זמן אמיתי לפריים. בלי כרטיס גרפי, רק להשוואה בין מקומות |
| `firstKillSec`, `killSec`, `dieSec` | שניות להרוג אויב, ולמות כשעומדים בקרב בלי לברוח |
| `freePlay.longestQuietSec` | הכי הרבה שניות ב-90 שניות משחק בלי "רגע": פריט חדש, חגיגה, קווסט, או כפתור בחירה שקפץ |
| `newPlayer.goalSec` | תוך כמה שניות בכפר מופיעה מטרה ברורה למעלה |
| `warden` | השומר האבן: קם, נפל, כמה זמן, והחיים הכי נמוכים |
