# fun-house

## זירת המקל · Stick Arena (דמו)

משחק מובייל של דמויות מקל: תנועה בגרירה, תקיפה אוטומטית, החלפה בין חרב לחץ וקשת, ובוס שנבנה לפי סגנון המשחק שלך.

המשחק יהיה באנגלית. בינתיים הוא נפתח בעברית, ובמסך הפתיחה יש מתג עברית/English.

אין צורך בהתקנה או בשרת. פותחים את `index.html` בדפדפן. לשחק מהטלפון: [זירת המקל](https://claude.ai/artifact/LmHn8j71y9RsGYBAE9SmMa).

חדש: הרעיונות של אוראל משוחקים בדמו. דלת זהב שמובילה לחדר מטבעות, פצצה ובאף בתוך אזורים מסוכנים, ובוס שמתעצבן כשבורחים ממנו.

הקוד מחולק לקבצים בתיקיות `js` ו-`css`. ההוראות ל-Claude והמבנה המלא נמצאים ב-[CLAUDE.md](CLAUDE.md).

תכנון המשחק: [game-design.md](game-design.md). עדכונים בין ה-Claude של ניר לזה של אוראל: [claude-channel.md](claude-channel.md).
