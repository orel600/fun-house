# fun-house

## זירת המקל (דמו)

משחק מובייל של דמויות מקל: תנועה בגרירה, תקיפה אוטומטית, החלפה בין חרב לרובה, ובוס שנבנה לפי סגנון המשחק שלך.

אין צורך בהתקנה או בשרת. פותחים את `index.html` בדפדפן.

חדש: הרעיונות של אוראל משוחקים בדמו. דלת זהב שמובילה לחדר מטבעות, פצצה ובאף בתוך אזורים מסוכנים, ובוס שמתעצבן כשבורחים ממנו.

הקוד מחולק לקבצים בתיקיות `js` ו-`css`. ההוראות ל-Claude והמבנה המלא נמצאים ב-[CLAUDE.md](CLAUDE.md).

תכנון המשחק: [game-design.md](game-design.md). עדכונים בין ה-Claude של ניר לזה של אוראל: [claude-channel.md](claude-channel.md).
